## 공급원에 확인할 구체 항목

1. 로그인 없는 공개 사이트의 시세·차트·변동률·파생 지표 재표시 권한. 지수와 ETF 대체값을 구별하고 실제 지수 이용권 포함 여부 확인.
2. 일별 지수·섹터, 장전 선물/해외 흐름, 경제 일정·결과, 기업 실적·콜 전문의 범위, 지연, 갱신 시각, 수정 이력.
3. 원문 발췌·저장·백업·정정 이력 보존의 허용 범위와 기간. 공급 계약 종료 후 보관·공개 정책.
4. 방문자 제한·필수 출처 문구·캐시·월 호출량·초과 요금·서버/개발 키 분리.
5. 한국어 AI 요약·추론·차트 생성에 입력 가능한지와 공개 파생 콘텐츠 조건.

FMP의 일반 가격표는 개인 사용과 별도로 표시·재배포 계약을 요구한다. 개인용 상위 요금제를 구매하면 공개 권한까지 생긴다고 판단하지 않는다. Twelve Data도 Business의 외부 표시 조건과 데이터별 권리를 확인해야 한다. 업체 문의는 발송하지 않았다. [FMP 가격·표시 계약](https://site.financialmodelingprep.com/developer/docs/pricing), [Twelve Data Business](https://twelvedata.com/pricing-business)

## 생성 작업 재개 시 연결 순서

현재는 이 순서를 실행하지 않는다. 관리자·화면·운영 기반 작업 이후 실제 생성 연결을 재개할 때 적용하며, 재개 시점의 공급원 제공 조건·모델 지원·가격은 다시 확인한다.

1. 기본 출처와 사건별 검색의 수집 경로를 연결하고, URL·게시 시각·관측 시각·기준 기간·근거 발췌를 기존 Bundle로 정규화한다. 웹 자료의 지시를 실행하지 않는다. 실제 시세는 대상 상품·이용 조건을 확인한 공급원에서 받으며 계약이 필요한 부분과 독립적인 공식 자료 수집은 병행한다.
2. 첫 시험용 비용 집계·중복 방지·차단을 로컬 모의 응답으로 검증한다. 현재 완료된 보호와 미구현 보호는 TECH_SPEC 8·12절에서 구분한다.
3. 시험 금액은 사용자 수락 완료. 모델·자료 경로·필요한 계정 설정과 비밀 설정을 준비한 뒤 승인된 비용 범위에서 실제 자료의 한 회차를 로컬 비공개로 생성한다. 실제 수치를 가상 샘플에 섞거나 공개 이용 조건을 통과하지 않은 자료를 공개하지 않는다. 생성 후 첨부 근거 대조를 포함해 기준 시각·수치·주요 사건 누락·사실/해석·읽을 가치·전체 시간·실제 비용을 확인한다.
4. 결과의 부족한 자료와 생성 지시를 보완하고 대표 상황으로 확인 범위를 넓힌다. 정해진 시험 일수를 채우는 절차는 추가하지 않는다. 공개 발행·외부 계정 운영·배포는 기존 승인 기준을 따른다.

현재 수동 Bundle 반입 경계를 자동 수집 완료로 보지 않는다. 시장 데이터 업체에 보낼 문의는 아직 발송하지 않았으며, 핵심 확인 항목은 위 목록을 사용한다. FMP의 표시 계약 요구와 Twelve Data의 외부 표시/분배 구분은 2026-11-17 공식 페이지에서 재확인했고 실제 프로젝트 견적은 없다.

생성은 `background: true`, `store: true`로 응답 ID를 보존하고 다음 작업에서 회수한다. 계정의 데이터 보관 정책과 호환성을 확인해야 한다. POST 응답이 불명확하면 자동 재요청을 중단한다. 관리자도 단순 재시도로 중복 과금을 일으킬 수 없으며 공급자 기록 확인 후 복구한다. [Background mode](https://developers.openai.com/api/docs/guides/background), [Structured outputs](https://developers.openai.com/api/docs/guides/structured-outputs), [모델 공식 문서](https://developers.openai.com/api/docs/models/gpt-6.1-sol)

비용 가정·산식은 [기술 명세 8절](TECH_SPEC.md#8-비용-예시와-남은-견적)에서 관리한다. 데이터 계약 견적이 없으므로 총 운영비 확정이나 무료 운영을 약속하지 않는다. 키는 대화·문서에 전달하지 않고 승인된 환경의 비밀 설정에 등록한다.
